# NSI Première — Supports de cours

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/SamiChabbi/nsi-premiere/main)

Supports de cours de NSI (Première) sous forme de notebooks Jupyter : cours, exercices avec tests pour s'autocorriger, et résolutions avec explications pédagogiques.

## Contenu

```
01_Matrices/
├── 01_Matrices_Cours.ipynb          tableaux à deux dimensions : m[i][j], parcours, construction, copie
├── 02_Matrices_Exercices.ipynb      16 exercices progressifs (⭐ à ⭐⭐⭐⭐) avec tests
└── 03_Matrices_Resolutions.ipynb    résolutions : ÉNONCÉ / RÉSOLUTION / EXPLICATION PÉDAGOGIQUE
```

| Chapitre | Thème |
|:---|:---|
| 01 | Les matrices (tableaux de tableaux) : carré magique, morpion, images, sudoku, jeu de la vie |

## Utilisation

- **En ligne :** cliquer sur le badge *Binder* ci-dessus (premier lancement : quelques minutes).
- **Sur son ordinateur :** `jupyter notebook` dans le dossier du dépôt.

Exécuter les cellules **dans l'ordre** (*Cell → Run All*). Les notebooks n'utilisent que Python standard.
