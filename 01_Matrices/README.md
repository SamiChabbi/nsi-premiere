# NSI Première — Les matrices (tableaux à deux dimensions)

Notebooks Jupyter pour apprendre à manipuler des tableaux de tableaux en Python, du cours jusqu'à des défis.

## Contenu

```
01_Matrices_Cours.ipynb          cours : m[i][j], parcours, construction avec des boucles, copie
02_Matrices_Exercices.ipynb      16 exercices à faire soi-même, avec des tests pour s'autocorriger
03_Matrices_Resolutions.ipynb    résolutions : ÉNONCÉ / RÉSOLUTION / EXPLICATION PÉDAGOGIQUE
```

| Partie | Exercices | Niveau |
|:---|:---|:---|
| A — Les bases | dimensions, matrice nulle, somme, maximum, compter | ⭐ à ⭐⭐ |
| B — Lignes, colonnes, diagonales | sommes, diagonales, transposée, symétrie | ⭐⭐ |
| C — Défis | carré magique, morpion, images, sudoku, spirale | ⭐⭐⭐ à ⭐⭐⭐⭐ |
| D — Projet | le jeu de la vie de Conway | ⭐⭐⭐ à ⭐⭐⭐⭐ |

## Utilisation

- Lancer `jupyter notebook` dans le dossier et ouvrir les notebooks dans l'ordre.
- Dans la feuille d'exercices : compléter chaque fonction, puis lancer la cellule **🧪 Tests** en dessous.
- Seul Python standard est utilisé (aucune bibliothèque à installer).
